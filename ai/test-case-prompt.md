# AI 테스트 케이스 생성 프롬프트

아래 템플릿을 ChatGPT / Claude 등에 붙여 넣어 사용합니다.
`[ ]` 부분만 바꿔서 화면별로 반복하세요.

---

## 프롬프트 템플릿

```
너는 5년 차 QA 엔지니어야. 아래 화면의 테스트 케이스를 설계해 줘.

[대상 화면]
쇼핑몰 결제 정보 입력 화면 (Checkout: Your Information)

[화면 구성]
- 입력란: First Name, Last Name, Zip/Postal Code
- 버튼: Continue, Cancel
- 오류 메시지 영역

[규칙]
- 세 입력란은 모두 필수
- 오류 메시지는 첫 번째 비어 있는 필드 기준으로 하나만 표시

[요청]
1. 정상 케이스, 예외 케이스, 경계값 케이스로 나눠서 작성
2. 각 케이스는 표로: ID | 제목 | 사전 조건 | 절차 | 기대 결과 | 우선순위(상/중/하)
3. 자동화 적합 여부(자동화 / 수동)도 표시
4. 자동화하기에 불안정할 수 있는 케이스는 이유를 한 줄로 설명
```

## 사용 팁

- 화면 설명이 구체적일수록 결과가 좋아집니다. 규칙(필수값, 길이 제한 등)을 꼭 적어 주세요.
- AI가 규칙에 없는 내용을 지어내는 경우가 있으니, **실제 사이트에서 직접 확인**하세요.
- 결과는 `test-case-log.md`에 채택/제외로 정리합니다.
