# AI 생성 테스트 케이스 검토 기록

AI가 만든 케이스를 **그대로 쓰지 않고 검토한 과정**을 기록합니다.
이 문서가 포트폴리오의 핵심 근거입니다.

## 요약 (작업할 때마다 갱신)

| 화면 | AI 생성 수 | 채택 | 제외 | 채택률 |
|------|-----------|------|------|--------|
| 로그인 | | | | |
| 결제 정보 입력 | | | | |
| 상품 정렬 | | | | |

## 상세 기록

### 화면: (예: 결제 정보 입력)

- 사용한 프롬프트: `test-case-prompt.md` 기준
- 사용한 AI / 날짜:

| AI 케이스 | 판정 | 이유 |
|-----------|------|------|
| 이름 공백 입력 시 에러 표시 | 채택 | 실제 사이트에서 확인 후 자동화 |
| (예) 이름 1000자 입력 | 제외 | 사이트에 글자 수 제한 규칙이 없어 기대 결과를 정할 수 없음 |
| (예) 이모지 입력 | 보류 | 규칙이 불명확해서 수동으로 먼저 확인 |

### AI 결과에서 발견한 문제

- (예) 존재하지 않는 규칙을 있는 것처럼 작성함
- (예) 서로 중복되는 케이스가 3개 있었음
- (예) 기대 결과가 모호해서 사람이 구체화함
